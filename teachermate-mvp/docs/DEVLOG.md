# 개발 일지

## 2026-10-16 · MVP 1차 구현

**목표**: 사업계획서(v4) 2-2의 MVP 3가지 — 연간 업무 타임라인, 리마인드 알림, 자료→업무흐름도 — 와 DB 보안 구조.

**한 일**
- Vite + React + TypeScript 웹앱 골격. 로컬 체험 모드(브라우저 저장)와 학교 계정 모드(Supabase) 두 가지로 동작.
- 1년 업무 지도: 3월~2월 학년도 띠, 주차별 할 일, 업무분장 필터, 초안/확정 구분.
- 학사력 불러오기: "3.2.(월) 입학식", "10.14~16 현장체험학습" 등 줄 단위 날짜 인식(AI 없이 화면 안에서 처리).
- 자료→업무 흐름: 규칙 기반 단계 추출 + 단계별 원문 근거 문장, 날짜가 없으면 비워 둠. 학교 계정 모드에서는 Claude 정리(동의 후).
- 리마인드: 확정된 일만 D-7/D-1/기한 지남으로 표시, .ics 내보내기로 휴대폰 캘린더 알림.
- 인수인계 카드: 요령·원본 위치·1년 일정을 텍스트로 내려받기.
- 개인정보 차단기(브라우저·서버·DB 3중), RLS 정책, 초대 코드 기반 학교 합류.

**검증**: 단위 테스트 17건 통과, 타입 검사·빌드 통과, RLS 공격 시나리오 9건 기대대로 차단.

**인터뷰 반영**: 타임라인 시각화(사립 4년 차), 캘린더 연동·데드라인 알림(공립 4년 차), 원본 위치 연결(공립 12년 차 NAS·학교 사용설명서), 학년 내 업무분장 표시.

**다음**: 파일럿 교사 피드백, 학년부장 대시보드 검토, 공문→할 일 자동 생성(Plus), 감사 로그.

**AI 도구 사용 표기**: 코드 초안 작성과 보안 설계 정리에 Claude(Anthropic)를 사용했고, 기능 범위와 원칙은 팀 사업계획서를 따랐다.

## 2026-10-19 · 학사력 자동 정리 원스톱 개편 ("파일 올리기 → 자동 정리 → 미리보기 확인·수정 → 초안 추가")

**목표**: 교사가 학사력 파일을 그대로 올려도 달력 표에서 날짜와 행사를 자동 짝지어 정리하고, 직관적인 표에서 확인·수정 후 1년 업무 지도로 바로 등록하는 원스톱 UX 구축.

**한 일**
1. **입력 인터페이스 전면 개편 (`src/components/CalendarImport.tsx`)**:
   - 파일 드롭존 전면 배치: PDF, Excel(.xlsx), 이미지(PNG/JPG) 지원.
   - 한글(HWP) 사용자용 안내 배너: "[파일] → [PDF로 저장하기] 후 업로드" 가이드 제공.
   - 보조 탭 분리: `📁 파일 올리기` / `✏️ 직접 텍스트 입력` 탭으로 유연성 유지.
   - 20,000자 글자 수 한도 제거: 3월~2월 1년 치 수백 건의 행사를 제약 없이 자동 처리.
2. **달력 표(Grid) 좌표 기반 PDF 파서 (`src/lib/pdfCalendarParser.ts`)**:
   - `pdfjs-dist`의 텍스트 좌표(x, y, bounding box)를 읽어 7개 요일 열과 주별 행을 클러스터링.
   - 달력 칸 단위로 일자(1~31)와 행사 텍스트를 정확히 1:1 매칭.
   - 요일 머리글(`일 SUN`…), 행사 없는 날짜 숫자, 음력 날짜, 24절기, 학교 바닥글(`http`·`Tel` 등) 자동 제거.
   - 줄바꿈된 행사명(괄호 미완성 등) 자연스럽게 병합.
   - 중대부초 2026 학사력 28페이지 전체 12개월(3월~2월)에서 230개 학사 일정 자동 추출 검증.
3. **엑셀(XLSX) 파서 (`src/lib/excelCalendarParser.ts`)**:
   - SheetJS(`xlsx`)를 적용하여 시트 내 날짜 셀 및 인접 행사명을 셀 단위로 추출.
4. **개인정보 검사(PII Guard) 정밀화 (`src/lib/piiGuard.ts`)**:
   - 정리된 행사 목록(제목) 기준으로 검사(`scanPiiForEvents`)하여 달력 날짜 숫자 나열로 인한 오탐 원천 차단.
   - 실제 주민번호·휴대전화·학생 명단은 철저히 차단.
5. **인터랙티브 미리보기 및 편집 표 (Preview Table UX)**:
   - 추출 즉시 날짜, 행사명, 업무분장 드롭다운, 상태('정상'/'확인 필요' 뱃지)를 표 형태로 제공.
   - 전체 선택/해제 및 개별 체크박스, 교사의 직접 수정, 행 삭제 지원.
   - "선택한 N건을 초안으로 추가 →" 버튼으로 1년 업무 지도(타임라인) 초안으로 일괄 등록.
6. **AI로 읽기 폴백 모달**:
   - 이미지(스캔·캡처본)이거나 규칙 기반 결과가 부족할 때 교사 명시적 동의 후 Edge Function 연동 안내.
   - 원본 파일 비저장(사업계획서 2-3 원칙) 및 브라우저 메모리 파싱 준수.

**검증**:
- 단위 테스트 25건 전체 통과 (`src/lib/lib.test.ts`): 목록형 샘플, 엑셀 샘플, 중대부초 2026 학사력 PDF(12개월) 그리드 추출, PII 오탐 방지 검증 포함.
- 프로덕션 빌드 `npm run build` 통과.
- 브라우저 서브에이전트 실화면 검증: 파일 드롭존, HWP 가이드 배너, 미리보기 편집 테이블 렌더링 확인.

**AI 도구 사용 표기**: 코드 작성 및 테스트 설계에 Claude(Anthropic)를 사용했고, 원칙과 범위는 팀 사업계획서를 따랐다.

## 2026-10-23 · 사업계획서 대조 후 빠진 기능 보완 (넘겨주기·Plus)

**목표**: 사업계획서 v4의 2-2 주요 기능·2-3 사용 시나리오·안전 원칙과 구현을 대조해 비어 있던 부분을 채운다.

**대조 결과**: 연간 업무 타임라인·리마인드·자료→업무흐름도(MVP 3종)와 인수인계 아카이브·업무 챗봇은 구현되어 있었다. 아래가 비어 있었다.

**한 일** (`src/lib/handoverDoc.ts`, 저장된 확정 기록만 엮고 AI는 쓰지 않는다)
1. **1년 기록 → 인수인계 카드 초안** (시나리오 ⑤): 업무분장을 고르면 확정한 일의 메모·체크리스트·원본 위치를 모아 카드 편집기에 초안으로 연다. 교사가 팁을 더하고 저장해야 확정된다.
2. **알림 → 선임자 요령 연결** (시나리오 ③): 할 일을 열면 같은 업무분장의 인수인계 카드 요령과 원본 위치(경로 복사)를 함께 보여 준다.
3. **학년 말 인수인계서 일괄 생성** (Plus): 업무분장별 카드·1년 일정·원본 위치 확인 목록(`[ ]`)을 한 파일로 내려받는다. 안전 원칙 "학년 말 인수인계 시 위치를 다시 확인한다"를 반영했다.
4. **전입·신규 교사용 '우리 학교 업무 안내서'** (Plus): 학교 전체 확정 일정을 3월~2월 월별로, 업무분장별 요령과 자료 위치를 한 문서로 만든다.

**범위 밖으로 둔 것**: 결제·플랜(사업계획서상 파일럿 이후), 파일럿 지표 수집, 인터뷰 요청 중 계획서 기능표에 없는 것(학년부장 대시보드, 미제출자 자동 독촉, 자주 쓰는 멘트).

**검증**: 단위 테스트 29건 통과(인수인계 문서 생성 4건 추가), `tsc` 타입 검사 통과.

**AI 도구 사용 표기**: 코드 작성에 Claude(Anthropic)를 사용했다.
